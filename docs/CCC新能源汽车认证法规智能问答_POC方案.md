# CCC 新能源汽车认证法规智能问答助手
## 第一版 POC 方案

### 1. 项目目标
面向内部法规工程师，构建一个覆盖 CCC 新能源汽车认证法规的检索与问答助手。系统需做到答案可溯源，检索不到的内容明确不回答。

### 2. 第一版范围

#### 2.1 包含
- 认证体系：CCC（暂不含 CE、UL）
- 产品类别：新能源汽车整车及关键部件（优先动力电池、充电、高压安全、EMC）
- 使用对象：内部法规工程师试用
- 数据形态：PDF 原件，包括扫描件、表格、中英文条款
- 核心功能：文档导入、条款级检索、带原文引用的问答、版本与作废状态标记

#### 2.2 不包含
- CE、UL 认证体系
- 对外部用户开放
- 法规自动更新监控
- 对外展示受版权限制的全文内容

### 3. 用户场景
- 法规工程师快速定位某类产品需满足的标准和条款。
- 通过自然语言提问，获得答案、标准号、条款号和原文引用。
- 核对新标准版本是否已生效，以及旧版本是否作废。

### 4. 核心流程
1. 上传法规 PDF
2. 识别是否为扫描件，扫描件先做 OCR
3. 提取条款、表格、标准号、版本、生效日期等元数据
4. 按条款级切分并建立检索索引
5. 用户提问后，先检索相关条款，再生成带引用的答案
6. 低置信度或检索不到时，只展示候选条款或提示未找到

### 5. 验收标准
- 建立 20 至 30 个高频问题的测试集。
- 测试集的问题，能定位到相关条款的召回率达到 90% 以上。
- 生成式答案中的标准号和条款号引用准确率达到 90% 以上。
- 无法回答的问题，明确拒绝，不编造答案。
- 法规工程师反馈检索耗时较人工明显缩短。

### 6. 高频问题清单（初稿）

#### 6.1 认证范围与标准
1. 新能源汽车整车进行 CCC 认证依据哪些标准？
2. 动力电池系统需要满足哪些 CCC 或强制性国标？
3. 充电接口和充电模式有哪些强制性要求？
4. 高压电气安全对绝缘、耐压、爬电距离有什么要求？
5. 电动汽车 EMC 测试依据哪个标准，包含哪些项目？
6. 电池包跌落、挤压、过充、热失控等安全测试的判定要求是什么？
7. 电动汽车与燃料电池汽车在 CCC 认证适用标准上有哪些差异？

#### 6.2 认证流程与资料
8. CCC 认证流程包括哪些阶段，通常需要多长时间？
9. 首次申请整车 CCC 需要提交哪些资料？
10. 工厂检查包含哪些内容，检查频率是多少？
11. 获证后产品一致性检查不合格会如何处理？
12. 进口新能源汽车的 CCC 认证要求是什么？

#### 6.3 证书、标志与变更
13. CCC 证书的有效期和延续申请如何办理？
14. 已获证产品发生关键元器件或结构变化，哪些必须重新检测？
15. CCC 标志应如何使用，铭牌和标志位置有什么要求？
16. 新能源汽车随车文件和警告标识有哪些强制要求？

#### 6.4 特殊情形
17. 哪些新能源汽车产品或部件可以豁免 CCC？
18. 电池回收或生产者责任延伸是否属于 CCC 认证范围？
19. 远程监控或安全监控平台是否有强制性标准要求？
20. 同一型号不同配置的车辆如何界定认证单元？

### 7. 需要提供的样本类型
建议提供 5 至 10 份文件，尽量覆盖以下类型：
- 标准原文的数字版 PDF
- 纯扫描版 PDF
- 包含大量表格的法规文件
- 同时包含中文和英文条款的文件
- 认证实施规则或实施细则
- 新版与旧版标准各一份，便于测试版本判断

### 8. 下一步
1. 收到样本后，先检查文件类型、扫描情况和 OCR 难度。
2. 根据样本确定解析与切分方案。
3. 搭建最小检索流程，并用高频问题清单验证召回效果。
4. 再加入生成式问答和引用展示。
