# CCC 新能源汽车法规有效版本核对表

> 核对日期：2026-09-19
> 用途：避免把已被代替或废止的标准当成现行文件入库。

## 一、核心结论

- 汽车 CCC 实施规则仍是 `CNCA-C11-01:2020`，没有废止，也没有更新的编号。
- `CQC-C1101-2020` 汽车实施细则仍现行，只是持续修订，最近一次修订为 2025-12-16。
- 标准版本已发生变化的：
  - `GB 18384-2020` 已被 `GB 18384-2025` 代替，2026-07-01 实施。
  - `GB 38031-2020` 已被 `GB 38031-2025` 代替，2026-07-01 实施。
  - `GB 7258-2017` 已被 `GB 7258-2026` 代替，新版 2027-07-01 实施，2017 版在 2027-06-30 前仍现行。
- `GB 38032-2020` 电动客车安全要求目前仍现行，未发现 2025/2026 新版。

## 三、建议补充的有效版本

- `GB 18384-2025` 电动汽车安全要求
- `GB 7258-2026` 机动车运行安全技术条件（已发布，2027-07-01 实施，用于时效管理测试）
- `CNCA-C11-01:2020` 强制性产品认证实施规则 汽车
- `CQC-C1101-2020` 强制性产品认证实施细则 汽车，最新修订版
- `GB 38032-2020` 电动客车安全要求（如业务覆盖客车）
- 电动汽车供电设备 CCC 规则/细则（依据市场监管总局 2024 年第 50 号公告，目录代码 2501/2502）

## 五、对系统的要求

法规库每条记录至少包含以下元数据：

- 标准/规则编号
- 名称
- 版本号
- 发布日期
- 实施日期
- 状态：现行 / 即将实施 / 被代替 / 废止
- 代替关系：代替哪个版本、被哪个版本代替
- 依据公告或技术决议
- 来源机构

检索和问答时，默认优先返回“现行”版本；如命中“被代替”版本，必须明确提示版本状态，避免给工程师过时结论。
